# Espaço Alívio da Dor & Estética

Protótipo estático e responsivo, pronto para GitHub Pages, Netlify ou hospedagem convencional.

## Antes da publicação definitiva

- Confirmar os serviços realmente oferecidos e ajustar os textos dos três cards.
- Inserir endereço, horário, Instagram e nome da profissional, caso ela autorize.
- Substituir as imagens ilustrativas por fotos reais do espaço e dos atendimentos.
- Remover `noindex, nofollow` de `dist/index.html` quando todas as informações estiverem confirmadas.

## Publicação no GitHub Pages

Envie o conteúdo da pasta `dist` para a raiz do repositório e ative o GitHub Pages na branch principal.
